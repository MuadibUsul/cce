# Claude 商业化交付全链路操盘手册 (Business & Operations SOP)

## 一、 核心商业闭环与产品矩阵

本体系的核心壁垒在于**"将脆弱的账号买卖，升级为绑定了静态住宅专线与反指纹沙箱的确定性生产力服务"**，同时保证客户 100% 使用官方原版 Claude Code CLI 与原生网页功能。

| 产品矩阵 | 目标客群 | 交付物形态 | 定价与毛利结构 |
| :--- | :--- | :--- | :--- |
| **1. 代充 + 防封环境套件**<br>*(现金流基本盘)* | 已有主号、怕被封号的开发者 | 自动化代充 ($20 Pro / $200 Max) + 专属防封卡密（一键挂载静态住宅 IP 与 CLI 沙箱） | 代充收 10%~15% 服务费 + 汇率差；<br>环境包收 ￥39~59/月（静态 IP 成本约 $1.5，**毛利 >75%**） |
| **2. 20x Max 集装箱成品号**<br>*(高溢价主力品)* | 重度 Vibe Coding 程序员、工作室 | 预充值 $200 Max 成品号 + 专属启动器（内置免登录凭证与死绑静态住宅专线） | 官方价 $200 + 技术防封溢价 $20~$40 + 低汇率通道折价 |
| **3. 临期/退订尾货 API 池**<br>*(利润回收池)* | 散户、轻量测试用户 | 将退订或剩余几天到期的成品号汇入 OAuth 粘性网关，按量折价售卖 | 沉没成本为 0，100% 纯利润回收 |

## 二、 全链路四步标准作业程序 (End-to-End SOP)

### 第一步：底层供应链筹备与批次隔离（防连坐底座）
1. **网络层（1:1 静态住宅死绑）**：
   - 采购纯净**双 ISP 静态住宅代理**（美区/英区为主），严禁使用机房数据中心 IP 或动态轮换 IP。
   - 通过本地 `Sing-box` 映射为独立端口（如 `10001 ~ 11000`），严格执行 `1 个账号 : 1 个固定指纹种子 : 1 条固定静态住宅 IP`。
2. **支付层（应对 Stripe Radar 连坐）**：
   - **批次隔离纪律**：每 **10 个账号** 划为一个独立风控单元（Batch）。同一单元使用同一发卡行卡段（BIN），不同单元之间绝对不混用支付卡段、账单地址模板和注册邮箱域名。
   - 一旦某个账号因极端原因被封，最多只影响同批次的几个号，绝不波及整个千级号池。

### 第二步：自研反指纹引擎建档与原生态注册（控制面）
1. **指纹首次生成与终身固化**：
   - 调用自研管理器的 `create_profile`，由 `BrowserForge` 生成符合真实硬件概率分布的 `{OS, User-Agent, Screen, WebGL, CPU核数}`，并由 `profile_id` 哈希生成固定噪声种子（Noise Seed），永久写入 SQLite。
   - **同构原则**：准备交付给 Mac 客户的号，创建时锁定 `os_type="macos"`；交付给 Windows 客户的号，锁定 `os_type="windows"`。
2. **启动前熔断预检（Kill Switch）**：
   - 每次唤醒 `Camoufox` 浏览器前，先通过绑定的静态代理请求 IP 元数据接口，核对当前出口 IP 是否与建档 IP 一致，并自动提取真实的 `Timezone`、`Latitude/Longitude`、`Locale` 注入 C++ 内核。若代理不通或 IP 漂移，直接报错阻断启动。
3. **注册与凭证提取**：
   - 在 `Camoufox` 窗口内完成 Claude 账号注册，并执行一次 `claude login` OAuth 授权。
   - 提取生成的 `~/.claude` 认证凭证目录与浏览器 Cookie 归档保存；关闭浏览器后自动执行缓存瘦身（清理 `cache2`、`shader-cache` 等），将单号磁盘占用控制在 **10MB 以内**。

### 第三步：原生态代充过盾（Payment Execution）
1. **严禁跨环境代充**：
   - 无论是成品号充值还是替客户代充，**必须在与该账号绑定的同一个指纹 Profile 和静态住宅 IP 下**打开 Stripe 结账页面。
   - 账单地址（Billing Address）的国家、州、邮编必须与当前静态住宅 IP 的归属地以及虚拟卡（VCC）的 AVS 校验规则保持一致。

### 第四步：三端无缝交付给客户（执行面）
客户付款后，发卡系统自动签发一张绑定了指定 `profile_id` 的 **专属卡密（Card Key）**。客户凭此卡密可在三端无缝使用：

1. **端一：官方原生 Claude Code CLI（主力场景）**
   - **客户操作**：在终端运行你提供的轻量级启动器 `claude-box cli --key=CARD_KEY`。
   - **底层动作**：启动器自动从你的服务端拉取该账号的认证凭证并解压到隔离目录，通过环境变量 `CLAUDE_CONFIG_DIR` 挂载；同时在本地拉起加密回环隧道（连接你服务端的专属静态住宅 IP），自动注入 `HTTPS_PROXY` 后直接拉起**官方原版 `claude` 命令**。
   - **客户体感**：100% 原生 Claude Code 体验，无需自己翻墙配 TUN，不干扰本地其他网络，且永久免登录。
2. **端二：Desktop 专属防封网页盒子（桌面网页场景）**
   - **客户操作**：运行 `claude-box desktop --key=CARD_KEY`。
   - **底层动作**：启动器按需拉取开源反指纹浏览器内核（Mac 端自动执行 `xattr -rd com.apple.quarantine` 消除公证弹窗），注入服务端固化的硬件指纹种子、已登录的 Cookie 以及本地加密代理隧道，直接打开 `claude.ai`。
3. **端三：Web 云端流化工作台（跨设备/工作室多人共享场景）**
   - **客户操作**：在任意设备（iPad / 公司电脑 / 手机浏览器）打开专属链接输入卡密。
   - **底层动作**：通过 WebRTC / KasmVNC 流化访问跑在你服务器容器里的 `Camoufox` 实例。物理硬件与出口 IP 永远留在你的机房，实现物理级 0 封号。

## 三、 护城河保护与防白嫖设计

1. **网关域名白名单锁死（防客户偷流量）**：
   - 客户端本地永远不出现上游静态住宅 IP 的真实账号密码，只连接你的中转网关。
   - 你的中转网关配置严格的 SNI / 域名白名单，**仅放行 `*.anthropic.com`、`*.claude.ai`、`*.stripe.com` 及 Cloudflare 验证域名**。客户即便抓包提取了本地代理端口，也无法拿去刷视频或跑其他爬虫。
2. **明确售后质保边界**：
   - 交付说明中明确写入："使用配套启动器 / 防封专线包享全周期质保；私自修改配置或提取账号在个人机场节点下裸登导致封号，系统后台可查 IP 异常记录，概不质保。"
